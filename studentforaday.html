Student for a Day

A production-ready web application built for Vancouver Island University's ITAS department to manage their student shadowing and recruitment program. I led all UX/UI design and front-end development for this team project, collaborating directly with VIU program chairs as the client.

The Problem

VIU's shadowing program had no digital infrastructure

VIU's ITAS department ran a "Student for a Day" program allowing prospective students to shadow current students and decide if the program was right for them. The entire process was manual — no way to track applications, manage waivers for underage students, or measure whether shadowing experiences were actually leading to enrollment.

The department needed a fully digital system that would handle student interest forms, automate communications to program chairs, manage parental waivers, and give faculty a dashboard to track all shadowing activity — with the goal of using that data to justify expanded funding.

My Role

UX/UI ownership from wireframe to production

While my teammates focused on backend development, Salesforce integration, and database architecture, I took full ownership of the user experience and front-end implementation. The client-facing interface was primarily my work.

Figma Design & Prototyping

Designed the full UI in Figma including the guest student interest form, confirmation screens, and program chair dashboard — with interactive prototype for client review and sign-off.

Front-End Development

Built all React components from scratch using Tailwind CSS, including the guest student form, confirmation page, visit dashboard for program chairs, header, footer, and error page.

Client Communication

Participated in direct meetings with VIU program chairs to gather requirements, present designs, and refine user stories based on real client feedback.

User Stories & Documentation

Wrote and refined user stories and acceptance criteria for all user types — guest students, program chairs, and parents — ensuring development stayed aligned with client needs.

The Solution

A fully digital shadowing management platform

The application was built with a React and Tailwind CSS front-end, a Node.js backend, MySQL database, Salesforce CRM integration for contact management, and deployed via Docker. The system handled the full lifecycle of a shadowing request from interest to completion.

Guest Student Interest Form

Prospective students submit their interest, select a program, and provide contact info. Automated emails are triggered to the appropriate program chair based on their selection.

Parental Waiver System

If the student is under 18, a digital waiver is automatically sent to a parent or guardian for electronic signature — no printed paperwork involved.

Program Chair Dashboard

Faculty can view all shadowing visits, mark sessions complete, and track outcomes — giving the department the data needed to measure program impact and justify funding.

Salesforce Integration

Student contact records flow directly into Salesforce, allowing the department to maintain long-term recruitment tracking alongside their existing CRM workflows.

Reflection

What I learned working with a real institutional client

This was my first experience designing and building for a real institutional client with real stakeholders. The program chairs had specific needs that weren't always obvious from the initial brief — requirements evolved through meetings, and the design had to adapt quickly.

Leading the UX/UI on a team project taught me how to communicate design decisions clearly to both developers and non-technical clients. When I presented the Figma prototype to program chairs, I had to explain not just what it looked like but why it was designed that way — and be ready to change it based on their feedback.

Working with Salesforce integration also gave me hands-on experience with CRM systems in a real deployment context, which reinforced how important data flows are in institutional software — it's not just about the UI, it's about where the data goes and who needs to act on it.
